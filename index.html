أهم أوامر Git

صفحة واحدة مختصرة — اضغط «نسخ» ثم الصق الأمر في الطرفية

الإعداد الأولي

تحديد الاسم الذي يظهر في الحفظ

git config --global user.name "Your Name"

تحديد البريد الإلكتروني

git config --global user.email "you@example.com"

عرض كل الإعدادات الحالية

git config --list

إنشاء ونسخ المستودعات

إنشاء مستودع جديد في المجلد الحالي

git init

نسخ مستودع موجود من الإنترنت

git clone <repo-url>

حفظ التعديلات (Commit)

معرفة حالة الملفات

git status

إضافة ملف واحد إلى منطقة التجهيز

git add file.txt

إضافة كل التعديلات

git add .

حفظ التعديلات مع رسالة

git commit -m "message"

إضافة كل التعديلات وحفظها بأمر واحد

git commit -am "message"

الفروع (Branches)

عرض الفروع

git branch

إنشاء فرع جديد

git branch new-branch

الانتقال إلى فرع

git checkout branch-name

إنشاء فرع والانتقال إليه مباشرة

git checkout -b new-branch

دمج فرع داخل الفرع الحالي

git merge branch-name

حذف فرع

git branch -d branch-name

المستودع البعيد (Remote)

ربط المستودع المحلي بمستودع بعيد

git remote add origin <repo-url>

رفع التعديلات لأول مرة

git push -u origin main

رفع التعديلات لاحقًا

git push

جلب آخر التعديلات من المستودع البعيد

git pull

عرض المستودعات البعيدة المرتبطة

git remote -v

التراجع والإصلاح

إلغاء تعديلات ملف لم يتم تجهيزه

git restore file.txt

إزالة ملف من منطقة التجهيز

git restore --staged file.txt

التراجع عن آخر حفظ مع إبقاء التعديلات

git reset --soft HEAD~1

إنشاء حفظ جديد يعكس تعديلات حفظ سابق

git revert <commit-hash>

حفظ التعديلات مؤقتًا جانبًا

git stash

استعادة التعديلات المحفوظة مؤقتًا

git stash pop

العرض والفحص

عرض سجل الحفظ

git log --oneline

عرض التعديلات غير المجهزة

git diff

عرض قائمة الملفات المتعقبة

git ls-files
لتجاهل ملفات معينة أنشئ ملفًا باسم .gitignore واكتب بداخله أسماء الملفات أو المجلدات.
